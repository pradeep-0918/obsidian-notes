# Juspay-Style Word Problems

These are typical real-world stories that map to array patterns.

### 1. Transaction Log 💳

- Find fraudulent transactions
- Maximum profit period
- Continuous spending

**Pattern:** Prefix Sum / Kadane

---

### 2. Server Load 📊

- Maximum requests in any window
- Peak traffic

**Pattern:** Sliding Window

---

### 3. Delivery Schedule 🚚

- Merge overlapping deliveries
- Free time intervals

**Pattern:** Merge Intervals

---

### 4. Stock Market 📈

- Best buy/sell
- Maximum profit

**Pattern:** Kadane / Greedy

---

### 5. Seating Arrangement 🪑

- Minimum swaps
- Group students

**Pattern:** Two Pointers

---

### 6. Memory Allocation 💾

- Find missing block
- Rearrange memory

**Pattern:** Cyclic Sort

---

### 7. Gaming Scores 🎮

- Longest winning streak
- Highest score window

**Pattern:** Sliding Window

---

### 8. Sensor Readings 🌡️

- Detect anomalies
- Maximum increase

**Pattern:** Prefix Sum / Kadane

---

### 9. Warehouse Inventory 📦

- Merge stock ranges
- Count available products

**Pattern:** Sorting + Merge

---

### 10. Highway Toll 🚗

- Cars in a segment
- Toll collection in a range

**Pattern:** Prefix Sum
